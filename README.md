Oracle SQL Database Project

Relational database project developed at Hochschule Bonn-Rhein-Sieg using Oracle SQL.

Technologies: Oracle SQL, SQL Developer
Topics: Relational database design, primary/foreign keys, constraints, N:M relationships, JOINs, OUTER JOINs, aggregation, GROUP BY/HAVING, subqueries and data manipulation.
